# Triage labels

The five canonical triage roles:

| Label | Role |
|---|---|
| `needs-triage` | New issue, not yet categorized |
| `needs-info` | Blocked on requester clarification |
| `ready-for-agent` | Clear enough for autonomous agent work |
| `ready-for-human` | Requires human design or decision |
| `wontfix` | Will not be addressed |
