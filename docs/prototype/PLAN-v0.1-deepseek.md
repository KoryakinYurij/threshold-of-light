# Прототип v0.1 — план работ (ветка `прототип-дипсик`)

> Этот план написан агентом Buffy для исполнителя (DeepSeek) и живёт в ветке
> `прототип-дипсик`. Это **не копия** `docs/prototype/TASKS-v0.1.md` из ветки
> `proto/v0.1` — свой план. Из чужого взята только сильная логика: порядок
> задач по «что владелец может пощупать», ресёрч вместо вопросов владельцу,
> один таск = один чат, честный финальный отчёт.

## Цель

Дать владельцу **пощупать** игру руками, чтобы у него появилось мнение по
14 дизайн-развилкам из `docs/design/OPEN-QUESTIONS.md`. Ветка одноразовая:
в `master` вернутся только выводы (ответы, числа, подобранные владельцем, итоговая запись в журнале), не код.

### Правила запуска Godot

1. Стандартная проверка таска: `godot --headless --path . <сцена> --quit-after 3600` —
   ожидается чистый выход без ошибок скриптов и сцен. Экрана нет, визуал
   проверяет владелец. `--quit-after` считает **кадры**, не секунды (`godot --help`:
   «Quit after the given number of iterations»), поэтому 3600 ≈ минута при 60 FPS.
   Сцену указывать явно: без неё поднимается `run/main_scene` из `project.godot`
   (сейчас `main_menu.tscn`), и проверяемый экран не запускается.
2. После добавления скрипта с `class_name` обязателен
   `godot --headless --path . --import`, иначе движок не увидит класс.
3. Кодировка консоли Windows: перед запуском `chcp 65001`, иначе кириллица
   в логах превращается в мусор.

## Правила для всех чатов по этой ветке

1. **Владельца не спрашивать.** Блокер → ресёрч: как это решают профессионалы
   в жанре (Hunt: Showdown, Slay the Spire, Hades, Dead Cells и т.п.), выбрать
   по балансу качество/трудозатраты, записать решение **с источниками**.
   Не «на усмотрение владельца», не «оставим TODO».
2. **Один таск = один чат.** Контекст не тянет больше.
3. **Один таск = один коммит** с внятным сообщением. Незавершённый таск
   не закрывать.
4. **Соблюдать:** ADR-003 (JSON: целые поля кастовать явно), ADR-004
   (мастер-сид ≤ 2^53−1), ADR-005 (автолоады без `class_name`), именование
   из `CONTEXT.md`.
5. **В `master` ничего не мержим** из этой ветки.
6. Каждый таск после T-02 заканчивается готовностью к сборке для владельца:
   `export_presets.cfg` (Windows) + `tools/build.cmd`. Сама сборка `.exe`
   запускается на машине владельца (Windows, `D:\Tools\Godot\4.7.1\godot.cmd`)
   — собирать там же, где ведётся работа.

## T-03b — Доработка боя (по итогам гейта владельца)

**Зачем.** Владелец сыграл билд T-03 и ответил на гейт: бой x7 — «нет»,
дэш — «правильно», телеграф — «видно заранее». Причины «нет»: **однообразие**,
**нет награды**, **слабое ощущение удара**. Решения — по практикам жанра
(источники внизу), не на вкус владельца.

### 1. Ощущение удара — главный дефект: попадание игрока без отдачи

Точек фидбэка в коде четыре, и попадания игрока среди них нет:

| Событие | Вызов | Тряска | Хит-стоп |
|---|---|---|---|
| Враг бьёт игрока | `pursuer.gd:63` | 0.9 | 0.09 |
| Смерть врага | `combat_arena.gd:80` (`notify_enemy_died`) | 0.55 | 0.06 |
| Дэш игрока | `scout.gd:68` | 0.35 | — |
| Замах игрока | `scout.gd:89` (`_attack`) | 0.25 | — |
| **Попадание игрока** | `melee_hitbox.gd:36 → hurtbox.gd:19 → health_component.gd:35` | **нет** | **нет** |

- [ ] Хит-стоп на попадании игрока: `emit_feedback(0.4, 0.06)` при удаче. У `MeleeHitbox` нет ссылки на арену (`melee_hitbox.gd:15` держит только `owner_entity`) — идти через `owner_entity.arena`.
- [ ] Slow-mo на смерть врага: `time_scale = 0.2` на 0.25с + тряска 0.7. **Заменяет**, а не дополняет уже существующий `emit_feedback(0.55, 0.06)` в `combat_arena.gd:80`. Требует параметризовать масштаб времени: сейчас `combat_arena.gd:72` жёстко ставит `Engine.time_scale = 0.05`. Учесть наложение на `DEATH_FADE = 0.28` (`pursuer.gd:6`) — фейд крутится на масштабируемом `delta`.
- [ ] Числа урона: всплывающий текст «-10» у цели, подъём 30px, fade 0.6с.
- [ ] Вспышка врага при попадании: белая вспышка 0.1с (отдельно от существующего `attack_flash`, `pursuer.gd:17`).
- [ ] Частицы попадания: 6 точек, разлёт 150px/s, жизнь 0.35с.
- [ ] Звук — TODO на T-07 (ассетов нет, не блокирует).

### 2. Награда за бой — кроме отладочного счётчика убийство не даёт ничего

Сейчас есть только `defeated_enemies` (`combat_arena.gd:28,79`) и статус
«Арена зачищена» при `>= 2` (`combat_arena.gd:81-82`). Ни дропа, ни валюты, ни лечения.

- [ ] Дроп при убийстве: 1–3 «осколка» летят к игроку, счётчик «Материалы: N» в HUD (задел под экономику T-05 / Q-08).
- [ ] Шанс 15% — дроп лечения +10 HP: убийство окупает выживание (StS/Hades).
- [ ] Подхват с эффектом, счётчик виден сразу.
- [ ] RNG дропа — через `SeedService.combat_seed`, а не голый `randf()`: в боевом коде сид сейчас не используется вообще, а воспроизводимость по сиду — предмет ADR-004.

### 3. Разнообразие — один тип врага и фиксированный состав

Оба врага в `combat_arena.tscn:52-86` — один и тот же `pursuer.gd`, по 30 HP.
Спавна в коде нет вообще: враги статичны в сцене, а зачистка захардкожена
как `defeated_enemies >= 2` (`combat_arena.gd:81`). Волны требуют сперва
завести спавнер и снять этот хардкод.

Телеграф работает — иерархию чтения не ломать.

- [ ] Спавнер волн в `combat_arena.gd` вместо статических `PursuerA`/`PursuerB`; снять хардкод `defeated_enemies >= 2`.
- [ ] «Рой»: быстрый, 10 HP, урон 10, мелкий, стаи по 2–3 (дёшево: перекраска/масштаб).
- [ ] «Стрелок»: держит дистанцию 180px, телеграф 0.6с → снаряд (против «дверной проблемы» — заставляет двигаться). Снаряд: урон 10, жизнь 1.5с (Q-14). `DamageData.AttackType.RANGED` уже объявлен (`damage_data.gd:5`) и не используется — задействовать его.
- [ ] Волны: 1) Преследователь + 2 Роя · 2) Преследователь + Стрелок · 3) 2 Стрелка. Статус «Волна N/3».
- [ ] Элитный аффикс: 1 враг в волне — HP×2.5 / скорость×1.5 / урон×1.6 (другой цвет), дроп ×2.
- [ ] Фаза отчаяния: HP **врага** < 25% → скорость ×1.4, темп атаки −30%.

**Числа — решены владельцем (2026-08-03), не блокеры:**

- Урон — **per-type правда**: Рой 10, Стрелок 10, Преследователь 25. Ползунок F1 «Урон врага» — рычаг только для Преследователя (как сейчас, `pursuer.gd:61`), на новых врагов не распространяется.
- Темп атаки в фазе отчаяния — **−30% на `RECOVER`** (0.28 → 0.196, `pursuer.gd:67`); честный кулдаун атаки 1.2с не вводим (остаётся в Q-14, руки владельца).
- Скорость элиты — **оставить 140×1.5 = 210 и 294 в отчаянии**: быстрее пешком, ответ — дэш (~890 px/s за 0.18с). Добавить `enemy_speed` в `RANGES` + ползунок F1 (§4).
