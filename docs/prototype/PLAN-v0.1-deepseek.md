# Прототип v0.1 — план работ (ветка `прототип-дипсик`)

> Этот план написан агентом Buffy для исполнителя (DeepSeek) и живёт в ветке
> `прототип-дипсик`. Это **не копия** `docs/prototype/TASKS-v0.1.md` из ветки
> `proto/v0.1` — свой план. Из чужого взята только сильная логика: порядок
> задач по «что владелец может пощупать», ресёрч вместо вопросов владельцу,
> один таск = один чат, честный финальный отчёт.

## Цель

Дать владельцу **пощупать** игру руками, чтобы у него появилось мнение по
14 дизайн-развилкам из `docs/design/OPEN-QUESTIONS.md`. Ветка одноразовая:
в `master` вернутся только выводы (ответы, числа, подобранные владельцем, итоговая запись в журнале), не код.

## Окружение

| Параметр | Значение |
|---|---|
| Машина | Windows-машина (работа идёт по SSH-туннелю, подробности — `docs/windows-development.md`; синхронизация файлов с VPS — через rclone-зеркало `~/projects/godot/work/`, см. `~/projects/godot/AGENTS.md`) |

### Правила запуска Godot

1. Стандартная проверка таска: `godot --headless --path . --quit-after 60` —
   ожидается чистый выход без ошибок скриптов и сцен. Экрана нет, визуал
   проверяет владелец.
2. После добавления скрипта с `class_name` обязателен
   `godot --headless --path . --import`, иначе движок не увидит класс.
3. Кодировка консоли Windows: перед запуском `chcp 65001`, иначе кириллица
   в логах превращается в мусор.

## Правила для всех чатов по этой ветке

1. **Владельца не спрашивать.** Блокер → ресёрч: как это решают профессионалы
   в жанре (Hunt: Showdown, Slay the Spire, Hades, Dead Cells и т.п.), выбрать
   по балансу качество/трудозатраты, записать решение **с источниками**.
   Не «на усмотрение владельца», не «оставим TODO».
2. **Один таск = один чат.** Контекст не тянет больше.
3. **Один таск = один коммит** с внятным сообщением. Незавершённый таск
   не закрывать.
4. **Соблюдать:** ADR-003 (JSON: целые поля кастовать явно), ADR-004
   (мастер-сид ≤ 2^53−1), ADR-005 (автолоады без `class_name`), именование
   из `CONTEXT.md`.
5. **В `master` ничего не мержим** из этой ветки.
6. Каждый таск после T-02 заканчивается готовностью к сборке для владельца:
   `export_presets.cfg` (Windows) + `tools/build.cmd`. Сама сборка `.exe`
   запускается на машине владельца (Windows, `D:\Tools\Godot\4.7.1\godot.cmd`)
   — собирать там же, где ведётся работа.

## T-03b — Доработка боя (по итогам гейта владельца)

**Зачем.** Владелец сыграл билд T-03 и ответил на гейт: бой x7 — «нет»,
дэш — «правильно», телеграф — «видно заранее». Причины «нет»: **однообразие**,
**нет награды**, **слабое ощущение удара**. Решения — по практикам жанра
(источники внизу), не на вкус владельца.

> Блоки 1–3 независимы и могут исполняться и коммититься по отдельности;
> порядок в тексте = приоритет (сначала ощущение удара).

### 1. Ощущение удара — главный дефект: удары игрока сейчас без отдачи

Хит-стоп и тряска есть только на ударе **врага** по игроку
(`pursuer.gd` → `emit_feedback(target.global_position, 0.9, 0.09)`); удар игрока даёт тряску 0.25
только в момент замаха (`scout._attack`), а само попадание
(`MeleeHitbox → Hurtbox → HealthComponent.take_damage`) — **ничего**.

- [ ] Хит-стоп на попадании игрока: `emit_feedback(pos_цели, 0.4, 0.06)` из `MeleeHitbox._on_area_entered` (сигнатура `emit_feedback(_at: Vector2, shake: float, stop_seconds: float)` — позиция **первый** аргумент). «При удаче»: контакт в `_on_area_entered` ≠ списанный урон (i-frames) — эмитить из `Hurtbox.take_attack`/после реального списания либо проверять результат.
- [ ] Slow-mo на смерть врага: `time_scale = 0.2` на 0.25с + тряска 0.7. **Конфликт с хит-стопом:** оба пишут в один глобальный `Engine.time_scale` (`emit_feedback` → 0.05, возврат в 1.0) — объединить в один менеджер времени; на смерть — только slow-mo (текущий hit-stop 0.06/тряска 0.55 из `notify_enemy_died` подчинить или убрать).
- [ ] Числа урона: всплывающий текст с фактическим уроном (`DamageData.amount`, не хардкод «-10») у цели, подъём 30px, fade 0.6с.
- [ ] Вспышка врага при попадании: белая вспышка 0.1с.
- [ ] Частицы попадания: 6 точек, разлёт 150px/s, жизнь 0.35с.
- [ ] Звук — TODO на T-07 (ассетов нет, не блокирует).

### 2. Награда за бой — сейчас убийство даёт ноль

- [ ] Дроп при убийстве: 1–3 «осколка» летят к игроку, счётчик «Материалы: N» в HUD (задел под экономику T-05 / Q-08). Счётчик — **только в рамках сессии, без сейва/персистентности** (точки сохранения — SPEC-01 §6; сейв с T-04; ADR-003 — про типы в JSON, не про сроки).
- [ ] Шанс 15% — дроп лечения +10 HP: убийство окупает выживание (StS/Hades).
- [ ] Подхват с эффектом, счётчик виден сразу.

### 3. Разнообразие — сейчас один тип врага и одинаковые составы

Телеграф работает — иерархию чтения не ломать.

> Примечание: сейчас враги лежат готовыми в сцене (`PursuerA`/`PursuerB`),
> runtime-спавна нет — волны требуют мини-системы спавна по составу.

- [ ] «Рой»: быстрый, 10 HP, урон 10, мелкий, стаи по 2–3 (дёшево: перекраска/масштаб).
- [ ] «Стрелок»: держит дистанцию 180px, телеграф 0.6с → снаряд (против «дверной проблемы» — заставляет двигаться). HP и урон снаряда задать (например, 20/10 — как у Преследователя).
- [ ] Волны: 1) Преследователь + 2 Роя · 2) Преследователь + Стрелок · 3) 2 Стрелка. Статус «Волна N/3». Конец боя сейчас захардкожен на `defeated_enemies >= 2` (`notify_enemy_died`) — переопределить: зачищен состав → следующая волна, зачищен состав 3 → победа арены.
- [ ] Элитный аффикс: 1 враг в волне — HP×2.5 / скорость×1.5 / урон×1.6 (другой цвет), дроп ×2.
- [ ] Фаза отчаяния: < 25% HP → скорость ×1.4, кулдаун атаки −30%, **с телеграфом** (смена цвета/замах) — одобренный владельцем телеграф не ломать.

**Решить до старта:** смерть игрока между волнами — рестарт волны или всей арены (сейчас `R` рестартит арену целиком); куда в v1-HUD (`Title`/`HP`/`Status`/`DeathLabel`) добавить «Материалы: N» и «Волна N/3».

### 4. Тюнинг и тесты

- [ ] Ползунки F1 для новых величин + дефолты в `combat_arena.gd` (+ обновить ассерт `panel.sliders.size() == 6` в `combat_smoke.gd` — иначе новый ползунок роняет тест).

Визуальные эффекты (тряска камеры — она уже на `randf_range`, частицы, разлёт осколков) — локальный шум разрешён.
- [ ] `tests/combat_smoke.gd`: сейчас ходит в жёсткие `get_node("PursuerA"/"PursuerB")` — при волнах заменить на проверку по типам; добавить: дроп при убийстве, снаряд стрелка, регресс «3 удара = смерть» зелёный.
