# ADR-002: Unstable loot loss rule (push-your-luck contract)

## Status

Accepted (2026-07-31, by readiness audit — `docs/research/phase-1-readiness-audit.md`, item 3)

## Context

Документы проекта формулировали правило нестабильной добычи противоречиво:

- `CONTEXT.md` (domain language): «lost on death/evacuation»;
- Промт-контракт §9: «нестабильные — теряются при поражении»;
- `docs/research/design-and-release-supplement.md` §2.3: «при успешной эвакуации нестабильная добыча должна сохраняться», с явной просьбой зафиксировать правило в ADR.

Для механики push-your-luck (design-supplement §2) это расхождение критично: если добыча теряется и при *успешной* эвакуации, решение «остановиться» ничего не банкует, и вся механика риск/эвакуация разваливается (оба результата одинаково наказуемы).

## Decision

Правило потерь по исходам экспедиции (стартовая гипотеза, калибруется плейтестами по §2.4–2.5 design-supplement):

| Исход | Закреплённые награды (Материалы и пр.) | Нестабильная добыча | Воспоминания/открытия |
|-------|----------------------------------------|---------------------|------------------------|
| Эвакуация на узле эвакуации | 100% | **100% (забанковано)** | 100% |
| Победа над guardian | 100% | 100% | 100% |
| Смерть | 100% | **0%** | ~50% (гипотеза) |

- Процент сохранения при смерти — рычаг №2 калибровки (§2.4); модули-«страховки» (Мастерская) могут поднимать его точечно.
- Досрочный выход не из точки эвакуации (штраф ~50–70%) — **не вводится в Phase 1**; единственный выход — узел эвакуации / guardian / смерть.
- Формулировка «нестабильная добыча теряется **только при смерти**» — каноническая. `CONTEXT.md` исправлен.

## Consequences

### Positive

- Push-your-luck работает как задумано: эвакуация = банкование, решение «глубже или домой» — осмысленное.
- Экономика (§3 design-supplement), HUD ставок (RiskPanel, §8) и тесты («смерть теряет только нестабильную часть», промт §16) получают единый контракт.
- Телеметрия `extracted(d, loot)` / `died(d, cause, loot_lost)` (§9.2) интерпретируется однозначно.

### Negative

- Потеря 100% нестабильной добычи при смерти — жёстко для среднего игрока; смягчение — только через поздние модули-страховки (сознательный дизайн-рычаг, не баг).

## Alternatives considered

- **Потеря при любой эвакуации** (как было в CONTEXT.md) — отклонено: убивает механику банкования.
- **Частичный штраф за «панический» выход вне точки эвакуации** (Loop Hero-style 60%) — отложено; если в будущем появится такая механика, ADR дополняется.
